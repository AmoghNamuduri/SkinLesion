# Dataset placeholder — HAM10000

Put the HAM10000 dataset in **`data/raw/`**. Any of these layouts works (images are found recursively):

```
data/raw/
├── HAM10000_metadata.csv          # required (Kaggle .csv or Dataverse .tab both accepted)
├── HAM10000_images_part_1/        # Kaggle layout ...
│   └── ISIC_0024306.jpg ...
└── HAM10000_images_part_2/
    └── ISIC_0029306.jpg ...
```

or a single flat `data/raw/images/*.jpg` folder.

Sources:
- Kaggle (cited by the paper): https://www.kaggle.com/datasets/kmader/skin-cancer-mnist-ham10000
- Harvard Dataverse (no login): https://doi.org/10.7910/DVN/DBW86T, or run `python scripts/download_data.py`

Everything else in `data/` (`organized/`, `subset/`, `features/`) is generated by
`scripts/prepare_data.py` and `scripts/run_ml.py`.

> Size: the full dataset is ~2.7 GB. GitHub rejects files > 100 MB and repos above a few GB,
> so `data/raw/` is git-ignored by default. If you want the repo to carry data, commit only the
> 700-image subset (`data/subset/`, ~180 MB in total, each file < 1 MB) or use Git LFS.
